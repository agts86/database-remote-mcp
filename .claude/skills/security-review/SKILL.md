# セキュリティレビュー スキル

このスキルはコードのセキュリティ上の問題を検出するワークフローを実行する。

## 実行手順

1. 変更されたファイルを `git diff` で取得する
2. 以下の観点でセキュリティレビューを行う:

### チェック項目

- **SQLインジェクション**: クエリにユーザー入力が直接結合されていないか
- **入力検証**: 外部入力（DBクエリ文字列など）のバリデーション漏れ
- **認証・認可**: エンドポイントへの不正アクセスの可能性
- **シークレット漏洩**: ハードコードされた認証情報・APIキーがないか
- **依存関係**: 脆弱性のある npm パッケージ（`pnpm audit` で確認）
- **エラーメッセージ**: スタックトレースや内部情報が露出していないか

3. 発見した問題を重要度（Critical / High / Medium / Low）付きで報告する
4. 修正方法を提案する
